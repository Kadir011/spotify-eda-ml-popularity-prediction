# 🎵 Spotify EDA & ML Popularity Prediction

Análisis exploratorio de datos y predicción de popularidad musical
usando Python, Pandas, Matplotlib, Seaborn y Scikit-learn.

## Contenido
- Limpieza avanzada de datos
- 5 consultas analíticas con insights reales
- 8 visualizaciones estilo Spotify
- Modelos ML: Random Forest + Regresión Logística
- Casos especiales: Juice WRLD y Avicii post-fallecimiento

## Dataset
[Spotify Music Dataset — Kaggle](https://www.kaggle.com/datasets/solomonameh/spotify-music-dataset)
